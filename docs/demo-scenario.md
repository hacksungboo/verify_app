# 시연 시나리오 (7분)

## 사전 준비 (발표 전)

- [ ] 사전 실험 완료 → 대시보드 `효과 측정`에 ‘도구 없이’ 실측치 입력 → **예시 지우기**
- [ ] 시연 서버 `IMAGE_TAG` 커밋 태그로 고정, `scripts/check.sh` 전부 ✓
- [ ] 브라우저 2개 탭: ① 로그인 화면 ② `시스템` 화면
- [ ] 폴백: 시연 영상 녹화본, 검수 완료된 리뷰 1건 (검수함에 남겨 두기)
- [ ] 발표 PC 해상도 확인 (워크스페이스는 1280px 이상에서 3단 레이아웃)

## 흐름

| 시간 | 화면 | 말할 것 |
|---|---|---|
| 0:00–0:30 | 슬라이드 | "AI 초안 생성 30초, 사람 검수 **N분(실측)**. 병목이 검수로 옮겨갔다." |
| 0:30–1:00 | 슬라이드/영상 | Before: 원문과 초안을 번갈아 보는 장면, 측정 결과 표 |
| 1:00–1:20 | 로그인 → 상단 배지 | "지금 이 화면은 **OCI 서울 리전 team-4-1**에서 응답하고 있어요." |
| 1:20–2:00 | 새 검수 → 샘플 불러오기 → 검수 시작 | 원문 3건 + AI 초안. 진행률이 실시간으로 올라감 |
| 2:00–4:00 | 워크스페이스 | ① 빨간 문장 클릭 → 오른쪽에 원문 근거 형광펜 "초안 40%, 원문 12%" ② `A`로 수정안 적용 → 교정 부호로 바뀜 ③ `J`로 다음, 고객사 바꿔치기·날짜 이동 ④ 근거 없는 문장은 삭제 제안 |
| 4:00–4:30 | 검수 완료 모달 | 검수 시간, 7개 중 몇 개 바로잡았는지, 최종본 |
| 4:30–5:30 | 효과 측정 | 시간 N분 → M분, 발견율 X% → Y%, 오탐 |
| 5:30–6:00 | 시스템 | 인스턴스 OCID·리전·Shape, Oracle 23ai, VECTOR 컬럼, 요청 경로 |
| 6:00–7:00 | 슬라이드 | 한계(놓친 오류 Z건, 오탐 W건) → "최종 결정은 사람, 불확실하면 확인 필요로" · 확장(PR 리뷰, 계약서) · 도쿄 예비 리전 |

## 키보드 (시연에서 효과 좋음)

`J` 다음 위험 문장 · `K` 이전 · `A` 수정안 적용 · `E` 직접 수정 · `I` 문제없음 · `U` 되돌리기

## 장애 대응

| 상황 | 대응 |
|---|---|
| 진행률이 안 올라감 | 자동으로 폴링 전환됨. 그래도 멈추면 검수함에서 완료된 건 열기 |
| OpenAI 장애/지연 | `AI_PROVIDER=rule` 로 재시작 (규칙 기반으로 7개 모두 잡음) |
| 공개 주소 접속 불가 | 앱 서버에서 `ssh -L 8080:127.0.0.1:8080` 후 `http://localhost:8080` (배지는 그대로 OCI 표시) |
| 전부 안 됨 | 녹화 영상 |
